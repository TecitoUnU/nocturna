El curso de Precálculo

Precálculo es la etapa que prepara el cálculo. Reúne álgebra, funciones, trigonometría, números complejos y geometría analítica, y trabaja sobre las herramientas que después sostienen las derivadas y las integrales: factorizar, resolver, simplificar, representar y relacionar. En este proyecto el curso se cuenta también en vídeo, con el material grabado y ordenado por temas.

Tecnología

Cómo está hecha

Todo funciona con presupuesto cero: planes gratuitos y herramientas open source.

Next.js 16 · TypeScript

Frontend y backend en un mismo proyecto. App Router, Server Components y Server Actions.

Supabase (Postgres + Auth + Storage)

Plan Free: 500 MB de base de datos, 1 GB de almacenamiento, 50 000 usuarios activos mensuales. Row Level Security para que el catálogo público sólo lea lo publicado.

YouTube (videos no listados)

Único servicio de alojamiento y reproducción. Se usa el reproductor oficial por iframe; no se descargan ni retransmiten videos.

Vercel (Hobby)

Despliegue gratuito con subdominio *.vercel.app. Cabeceras de seguridad, CSP con nonce por petición y Content-Security-Policy que sólo permite el reproductor de YouTube.

Diseño editorial

Fondo negro azulado, texto blanco cálido, un único acento violeta eléctrico, Instrument Serif + Geist. Retícula asimétrica, sin cuadrícula genérica de tarjetas idénticas.

Seguridad

Validación de enlaces de YouTube en el servidor, sin HTML/JS arbitrario, políticas RLS en PostgreSQL, sin clave service_role en el cliente.

Nota: los videos no listados de YouTube no son privados ni están protegidos con contraseña: cualquiera que conozca el enlace puede verlos y compartirlos. NOCTURNA no promete lo contrario.
